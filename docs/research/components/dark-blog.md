# Component Spec — Dark Blog

## Components

- `BlogNav` — category filter tabs.
- `PostList` — sticky editorial sidebar and post cards.
- `FeaturedPanel` — atmospheric hero card for active post.
- `Article` — active post reader.
- `NewsletterCard` — static subscription callout.

## Requirements

- No external brand references.
- Dark-first palette with warm gold accent.
- Responsive, editorial, polished visual style.
- Content is local static data in `src/app/page.tsx`.

## Acceptance

- Category filtering works.
- Post selection works.
- Lint, typecheck, and production build pass.
