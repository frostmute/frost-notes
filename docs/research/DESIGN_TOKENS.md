# Design Tokens — Frost Notes Blog

## Typography

- Sans: `Geist Variable`
- Mono: `Geist Mono Variable`
- Body: `14px / 1.55`
- Hero title: clamp from `44px` to `96px`, tight tracking
- Article body: clamp from `16px` to `19px`, `1.85` line height
- Labels: mono uppercase, `10px–11px`, wide tracking

## Palette

- Faint: `#5e6674`

## Layout

- Desktop: category nav across top, sticky post index on left, reading pane on right.
- Tablet/mobile: stacked layout; post cards become a responsive grid, then single column.
- Visual style: glassy dark panels, warm gold accent, radial atmospheric background.
