# Behaviors — Frost Notes Blog

## Interactions

- Category tabs filter posts.
- Selecting a post updates the featured visual, metadata, article text, and tags.
- Newsletter form prevents default submit for static demo behavior.

## Visual states

- Active category uses the warm gold accent pill.
- Active post card uses a gold/violet gradient panel and elevated shadow.
- Hover states lift post cards and reveal brighter panel borders.
- Inputs receive an accent focus ring.

## Motion

- Subtle transitions use `cubic-bezier(.22, .7, .2, 1)`.
- No mandatory animations; the visual atmosphere comes from layered gradients and static orbs.
