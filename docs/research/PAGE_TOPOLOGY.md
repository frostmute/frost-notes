# Page Topology — Frost Notes Blog

## Structure

1. `BlogNav`
   - Sticky category filter bar.
   - Categories: All, AI, Systems, Web, Notes.
2. `PostList`
   - Brand block and editorial description.
   - Filtered list of selectable post cards.
   - Sticky left rail on desktop.
3. `ReadingPane`
   - `FeaturedPanel` with atmospheric abstract visual.
   - `Article` with metadata and body copy.
   - `NewsletterCard` signup callout.

## Responsive behavior

- Desktop uses a two-column editorial shell.
- Below `980px`, the layout stacks and post cards become two columns.
- Below `640px`, post cards collapse to one column and panels receive tighter padding.
