I have always believed that the tools we build should be as transparent as the work they produce. The architecture of this site—the mathematical dial, the frontmatter-driven gears, the complete absence of a database or server backend—was originally built purely for my own use as a personal portfolio. 

However, because it is entirely local-first and decay-resistant, it makes a perfect blank slate for anyone who wants to own their data and experiment with non-linear interfaces.

Today, I am officially open-sourcing the underlying machinery of this site as a template.

### The Antikythera Template

You can find the repository here: [github.com/frostmute/antikythera-template](https://github.com/frostmute/antikythera-template)

I have packaged up the core engine and stripped out all of my personal essays, projects, and photographs. The template repository contains a clean, sanitized workspace with a few placeholder Markdown files to demonstrate how the frontmatter schema places articles onto the dial's orbits. 

It is completely ready for you to clone, tinker with, and deploy to any static host (like Vercel or GitHub Pages) without needing a single build step. 

If you do build something with it, I would love to see how you turn the dial.
